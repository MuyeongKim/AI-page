# 랜딩페이지 사진 출처

현재 프로그램 화면은 `docs/images/manual-main-V26.1018.png`입니다. V26.1018 소스의 초기 GUI를 macOS 개발 환경에서 렌더링한 실제 위젯 화면이며, Windows 실행 파일의 인수시험 화면은 아닙니다. 실행 장치와 시스템 표시가 PC에 따라 달라질 수 있음을 웹과 설명서에 표시합니다. 이전 V26.1014·V26.0908 화면은 보관합니다.

웹 사용설명서는 `output/pdf/Stay-Up-AI-사용설명서-V26.1018.pdf` 원본입니다. 현재 화면과 PDF는 Astro에서 직접 가져와 해시가 포함된 URL로 제공하며 웹용 사본을 따로 편집하지 않습니다. `docs/manual-build.md`에 생성·검수 방법을 기록합니다.

운용 문서 전체 페이지, 범용 AI 생성 이미지는 새 랜딩페이지에 포함하지 않았습니다.
사진에 보이는 탐지 수치와 화면은 당시 시연 기록이며 현재 버전의 성능 보증 자료로
사용하지 않습니다.
