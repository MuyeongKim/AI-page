실행한 Windows 초기 설정 화면이며, 같은 버전의 사용설명서와 웹사이트에서 원본을 함께
사용합니다. V26.0905의 웹 전용 화면은 교체했습니다. 아래의 이전 시연 기록과 구분해

화면과 PDF는 Astro에서 직접 가져와 내용 해시가 포함된 URL로 배포하며, 웹용 사본을
별도로 편집하지 않습니다. 원본 문서와 생성 방법은 `docs/manual-build.md`를 참고하세요.
