- 실시간 저장 오류가 다음 이벤트에 가려지는 문제와 구간 선택 전환 시 미저장 메모가 사라지는 문제를 보완했다. 최근 알림·장면 저장 완료/실패와 저장 경고를 구분하고, 음소거는 소리만 끄는 동작을 유지한다.

- 사진 진행창에 현재·누적 사람/차량 후보, 성공·실패와 후보가 있는 사진 수를 표시한다. 실패는 미탐지와 구분하고 단계 전환·취소 중에도 마지막 완료 통계를 유지한다.
- 결과와 비교창에서 이전·다음 사진, PageUp/PageDown·Alt+방향키, 탐지본/원본 비교 전환을 제공한다. 한 번에 현재 사진 쌍만 읽으며 기존 100%·확대·이동과 누락 파일 안내를 유지한다. 영상 파일 열기와 후보별 판정·기록·내보내기는 유지한다.

## 2026.10.18 (버전 V26.1018)

- 같은 PC 폴더 연계 2단계: 사진 분석 종료·사진 기록 열기·저장된 판정을 선택 폴더의 작업 UUID별 JSON으로 자동 게시한다. 상황판은 읽기 전용으로 약 2초 간격 자동 갱신하며 수동 불러오기·기존 상황·대응을 유지한다. 반복 내용은 재작성하지 않고 과거/충돌 출력은 거부한다. 연결은 세션 한정이다.
- 사진 후보 파일 연계 1단계를 추가했다. 작업 결과·이전 후보 확인창에서 작은 JPEG·사진 촬영 정보·후보 판정을 내보낸다. 작업 UUID와 내용 리비전을 기록에 보관해 폴더 복사·다른 PC 전달·반복 및 판정 변경 내보내기를 지원한다. 상황판에서 기존 상황·대응을 보존하는 추가/갱신으로 읽는다. 실시간 자동 전송과 위치 OCR은 포함하지 않는다.
- 실제 실행에서 재현한 4건을 같은 버전에서 보완했다. 느린 연속 양성 프레임은 한 구간으로 유지해 알림·자동 장면 저장이 누락되지 않게 하고, 실제 미탐지 관측이 있을 때만 구간 연결 간격을 적용한다.
- 워커 종료 시 편집 큐를 잠금 안에서 닫고, 확인받지 못한 메모·판정은 최종 기록에 다시 저장해 검증한다. 저장 실패 요청과 아직 저장하지 않은 입력은 화면에 유지하며 재시도한다.
- 새 기록을 검증·생성한 후 기존 확인 창을 교체해 잘못된 JSON 이후에도 정상 기록을 다시 열 수 있게 했다.
- 후보 확인에서 원본 누락·읽기 실패·크기 불일치·열람 후 파일 변경을 검사한다. 이때 사람 맞음·오탐 버튼과 단축키 저장을 막고 보류만 허용한다. 기존 판정은 자동 변경하지 않는다.
- 소스·GUI 안내·릴리스 피드·웹사이트·사용설명서의 기준 버전을 V26.1018로 확정했다. Windows 실행 파일은 재빌드·검증 후 공개하며 다운로드는 준비 중으로 표시한다.
- 사진 선택 목록·동봉 모델 검색·원본 100% 비교·분석 프리셋·FPS 구분·run_summary.json 실행 기록 개선을 함께 포함했다.
- 하위 사진 폴더를 읽고 중복 입력·프로그램 결과 폴더 재분석·링크 순환을 방지한다.
- 사진별 처리 결과와 사람 후보별 ID·화면 좌표·신뢰도·확인 상태를 `detections.json`에 원자적으로 저장한다.
- 촬영 위치와 사람 위치를 구분하고 시간대 없는 촬영 시각은 임의로 보정하지 않는다.
- 사람 후보의 주변 원본 픽셀을 최대 480px 보조 JPEG로 저장한다. 저장 실패는 기록에 안내하고 기존 탐지 결과는 유지한다.
- 후보별 확인 화면에서 ←/→ 이동과 1/2/3 판정을 지원한다. 원본 위에 현재 후보를 표시하고 100% 보기·기존 비교창을 연결하며, 이전 기록을 다시 열어 판정을 유지한다.
- 탐지 종료와 후보 판정 변경 후 `search_report.html`을 생성한다. 상위 6건 이미지와 전체 후보 부록·촬영 위치·오류를 포함하고 외부 요청 없이 표시한다.
- 캡처보드 워커의 탐지 결과에서 시간 구간을 기록하고 별도 신뢰도·연속 프레임·반복 간격으로 알림을 제한한다. 미리보기의 최신 1장·20fps 구조를 유지한다.
- 실시간 기록의 메모·판정, 메신저용 문구 복사, UTF-8 BOM CSV와 보고서를 제공한다. CSV 메모는 수식으로 실행되지 않게 처리한다.
- 사용자 승인에 따라 알림 자동 장면과 Space 수동 장면을 정지 JPEG로 저장한다. 연결 끊김·취소·오류에도 기존 장면과 기록을 보존하며 영상 녹화는 추가하지 않는다.

## 2026.10.07 (소스 개선 · EXE 재빌드 전)

- 최신 공개 버전과 릴리스 날짜는 V26.1014 / 2026-10-14이다. 아래 변경은 기존 2026.10.07 작업 기록이며 최신 공개 ZIP에도 포함되지 않은 로컬 소스 개선으로, 로컬 환경 정비 및 EXE 재빌드 후 별도 배포가 필요하다.
- 여러 사진을 고르면 선택 수를 표시하고, 목록에서 불필요한 사진만 개별 제거할 수 있게 했다. 원본 파일을 삭제하지 않는다.
- 작업 폴더가 달라도 EXE 옆에 동봉한 모델을 찾도록 보완했다. 기존 모델 매핑은 유지한다.
- 원본·탐지본 비교에 실제 원본 픽셀의 100% 보기, 휠 확대·축소, 드래그·방향키 동기 이동과 화면 맞춤을 추가했다. 일부 대형 이미지의 비교창 열기 제한은 메모리 보호 안내로 알린다.
- 빠른 분석(V26 최소·640)·균형 분석(V26 소·1280)·정밀 분석(V26 최대·1920)과 장치별 추천을 추가했다. CPU는 빠른 분석, GPU/MPS는 균형 분석을 추천한다. 사용자가 직접 적용하며 시작 기본값 1920·신뢰도 10%·사람+차량은 유지한다. 프리셋은 모델·해상도만 바꾼다.
- 모델 전처리·추론·후처리에 따른 추정 FPS와 읽기·표시 준비·저장을 포함한 이전 완료 프레임의 처리 FPS를 구분한다. 프레임 처리 FPS는 모델 준비·종료 후 검증 시간을 포함하지 않는다.
- 실행 폴더가 만들어진 작업은 종료 시 `run_summary.json`에 버전·입력과 설정·시간·상태·결과·오류를 자동 기록한다. 모델 준비 실패나 분석 전 취소로 폴더가 없으면 기록도 없으며, 후속 GPS 분석 결과는 포함하지 않는다. 요약 저장 실패는 경고로 알리고 탐지 결과는 보존한다.
- 공개 릴리스 피드·사이트·PDF·이미지 및 라이브러리 구성은 변경하지 않았다. 이전 배포 이력은 아래에 보존한다.
