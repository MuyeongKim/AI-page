## 2026.09.05 (버전 V26.0905)
- 사진·영상의 최종 게시를 프로세스 간 잠금으로 보호하고, 원본도 임시 복사 후 게시한다. 사진 원본·탐지본의 번호를 맞추고 게시 실패 파일을 정리한다.
- Esc도 취소 요청으로 처리하고 단계별 진행·경과시간을 표시한다. 작업 스레드의 종료 신호를 처리할 때까지 진행·종료 상태를 유지한다.
- 닫힌 선택칸의 휠 변경을 막고 옵션 이름·화살표·글씨·장치 전환 표시를 보완했다. 실행·상태 영역은 하단에 고정했다.
- 마지막 작업 요약·전체 오류 목록과 파일 열기·저장 폴더 열기·원본 및 탐지본 비교를 작업 결과 탭에 추가했다. 요약은 현재 실행 중에만 유지한다.
- GPS 후속 분석을 백그라운드에서 수행하고 위치 발견·GPS 없음·오류·취소를 안내한다. 여러 위치를 한눈에 보여주고 마커에는 안전하게 처리한 사진 파일명을 표시한다.
- 빈 인증 입력은 재입력하게 하고, 공지의 HTTPS 링크를 클릭해 열 수 있도록 했다.
- 웹 관리자 수정 충돌 시 작성 내용을 보존하고 최신 저장본 비교 후 재시도를 지원한다. 소개 페이지의 긴 문자열·한글 줄바꿈과 현재 GUI 소개를 보완했다.
- README·창 제목·GUI 안내·공개 릴리스 피드를 V26.0905로 맞췄다. 이전 버전의 이력은 그대로 보존한다.
