# L1·L2 실시간 이벤트와 알림·기록

- 캡처보드의 워커 추론 결과만 사용한다. 기존 신뢰도·탐지 클래스·모델·모든 프레임 처리와 최신 1장/20fps 미리보기는 유지한다.
- 탐지가 끊긴 간격(기본 2초)으로 이벤트를 묶고 고유 인원·동일인 추적으로 표현하지 않는다.
- 알림은 별도 신뢰도(기본 50%)·연속 프레임(3)·반복 간격(5초)으로 제한한다. 설정은 사용자 조정 가능하며 탐지 판단은 바꾸지 않는다.
- 이벤트별 시작/마지막 탐지 시각·지속·최대 동시 인원·최고 신뢰도·메모·확인 상태를 보존한다.
- JSON을 원본 기록으로 원자 저장하고 UTF-8 BOM CSV를 만든다. 메모의 스프레드시트 수식 실행을 방지한다.
- 실시간 편집은 워커의 명령함으로 전달한다. 종료 후 편집은 파일 잠금으로 최신 기록을 읽고 해당 이벤트만 바꾼다.
- 미리보기 창에서 알림 음소거·기록·메모·보고 문구 복사, 종료 후 기록 재열기·보고서를 제공한다.
- 취소·연결 끊김·오류 시 열린 구간을 마감하고 기록을 보존한다. 자동 재연결은 추가하지 않는다.
- 검증: 간격/연속 프레임/반복 억제·메모·중단 보존·CSV/주입 방지·키보드·기존 미리보기 역압력 회귀검사.
