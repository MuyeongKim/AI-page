# C4 오프라인 후보 확인 보고서

- 승인된 search_report.html 한 파일에 스타일·상위 후보 이미지·위치·확인 집계·설정·오류를 포함한다.
- 요약은 상위 6건으로 1~2쪽 인쇄를 목표로 하고 모든 후보를 부록 표에 남긴다. 촬영 위치/고유 인원 아님/미확인을 명시한다.
- 탐지 종료 시 자동 생성하고 후보 확인 변경 후 재생성한다. 다시 연 기록에서도 만들고 열 수 있다.
- 원본 경로·메모·오류는 HTML 이스케이프한다. 이미지는 실행 폴더 안의 작은 JPEG만 내장하고 외부 요청은 하지 않는다.
- 기존 파일을 원자적으로 바꾸고 생성 실패 시 탐지·판정 결과를 보존해 안내한다.
- 검증: 후보 전체 보존·확인 집계·오류/부분 완료·외부 요청 없음·문구 주입 방지·저장 실패 보존·실제 HTML 인쇄.
