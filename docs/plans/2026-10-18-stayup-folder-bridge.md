# 같은 PC 폴더 연계 2단계

2026-10-18 사용자 승인: 사진 후보 자동 저장·폴더 읽기, 기존 수동 불러오기와 상황·대응 기록 유지, 실제 실행 후 두 저장소의 GitHub·GitLab에 커밋·푸시. AI-page V26.1018 유지. EXE는 사용자가 제작한다.

- 탐지 프로그램에서 사용자가 연결 폴더를 선택한다. 완료된 사진 분석과 열어 둔 사진 기록의 저장된 판정을 백그라운드에서 내보낸다. 진행 중 분석·실시간 영상은 대상이 아니다.
- 자동 파일은 `stayup-ai-candidates-<작업 UUID>.json`. 같은 작업은 원자 교체하며 여러 작업을 함께 보관한다. 기존 수동 파일·공통 형식 v1은 유지한다. 자동 저장은 같은 내용의 파일을 다시 쓰지 않으며 최신 파일을 과거/충돌 내용으로 덮지 않는다.
- 상황판은 사용자가 선택·확인한 폴더의 바로 아래 후보 파일만 약 2초 간격으로 읽는다. Chromium의 읽기 전용 File System Access 권한을 사용한다. 하위 폴더·다른 JSON·임시 파일은 읽지 않는다. 한 폴더 최대 500개 후보 파일·전체 64 MiB, 개별 16 MiB 제한.
- 기존 ID·리비전 검증/대응 보존/복구점/이미지 저장을 재사용한다. 반복 내용은 쓰기·이력 추가 없이 건너뛴다. 잘못된 파일은 제외하고 오류를 표시하며 정상 파일은 계속 처리한다. 파일 삭제도 기존 후보·대응 기록을 삭제하지 않는다.
- 연결은 현재 창·현재 상황에만 유효하다. 새로고침·상황 복원·초기화·완전삭제·수동 AI 가져오기·편집권 상실·폴더 권한 상실 시 해제한다. 늦게 완료된 작업도 새 상황에 반영하지 않는다. 연결 경로/핸들은 백업·영구 저장하지 않는다. 폴더 연결 해제는 이미 저장된 기록을 삭제하지 않는다.
- UI 기준: 기존 AI-page 결과 카드/상황판 AI 후보와 보관 파일 지정 흐름을 유지한다. 연결·해제 버튼, 폴더명, 마지막 확인시각, 성공/오류 수를 일반 텍스트로 안내하고 키보드·390px에서 확인한다. Refero craft의 명시적 상태·포커스, typography의 업무도구 밀도를 적용한다.
- 테스트 우선: 자동 내보내기 파일명·리비전·반복/충돌·디스크 오류·스레드 종료/취소·판정 변경, 브라우저 정상/중복/복수작업/오류/삭제/권한/늦은 완료/수동 유지/복원·기록 보존. 실제 로컬 폴더와 실제 Chrome 파일시스템 핸들, Cocoa GUI로 연결 흐름 검증.
- 다른 PC 자동 전송·좌표 OCR·실시간 이벤트 자동 연계는 후속이다. Windows EXE·기관망·물리 캡처보드 인수시험은 별도다.
