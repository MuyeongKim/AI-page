# C1 사진·후보별 탐지 기록

- 승인된 detections.json을 실행 폴더에 원자적으로 기록한다. 저장 실패는 경고이며 탐지 결과를 삭제하지 않는다.
- 사진별 ID·성공/실패·메타데이터와 후보 박스별 ID·신뢰도·확인 상태를 저장한다.
- 미탐지·EXIF 없음·손상 메타데이터를 구분하고 EXIF 시각의 시간대가 없으면 추정하지 않는다.
- 좌표와 image_size는 YOLO 원본 화면 기준(EXIF 방향 적용)이다. GPS는 photo_gps 촬영 위치다.
- 읽을 때 형식·중복 ID·상태·유한 좌표·상대 파일 경로를 검증한다. 보고서·후보 확인에서 같은 계약을 사용한다.
- 검증: 다중 후보·미탐지·실패·저장 오류·비정상 좌표·메타데이터·기존 탐지 인자 불변.
