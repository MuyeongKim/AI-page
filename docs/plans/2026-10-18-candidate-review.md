# C2 후보별 확인

- 기존 ResultComparisonDialog·SelectedFilesDialog를 화면 기준으로 사용한다. Refero의 craft-details(포커스·인라인 오류), typography(업무 화면의 중립적 글자와 밀도)를 보조 기준으로 삼는다.
- 기존 배경·글꼴·버튼을 유지하고 상단 후보 번호/판정, 가운데 원본 후보 확대, 하단 이전/다음·확인 버튼을 둔다. 장식·새 UI 라이브러리를 추가하지 않는다.
- 화살표로 이동하고 1/2/3으로 사람 맞음/오탐/보류를 저장한다. 저장 실패 시 상태를 바꾸지 않고 바로 안내한다.
- 같은 실행 폴더 기록을 다시 열고 개별 후보 판정을 유지한다. 원본 비교 화면을 재사용하고 파일 경로를 검증한다.
- 다른 창에서 수정한 후보 상태를 보존하도록 잠금 후 최신 기록을 읽고 해당 후보만 갱신한다.
- 검증: 다중 후보 독립 판정·키보드·다시 열기·쓰기 실패·누락 파일·560px 화면.
