# L3 승인된 정지 장면 저장

- 2026-10-18 사용자 승인: 알림 장면 자동 저장과 스페이스바 수동 저장을 허용했다.
- 워커의 현재 캡처 프레임을 JPEG로 실행 폴더 scenes/에 원자 저장한다. 영상 녹화는 추가하지 않는다.
- 자동 장면은 알림의 연속 프레임/별도 신뢰도/반복 억제 기준을 공유한다. 수동 저장은 사람이 안 잡혀도 가능하며 사람 탐지로 기록하지 않는다.
- UI 요청은 스레드 안전 명령함으로 전달한다. 이전 실행 프레임이나 저장 요청 뒤 받지 못한 프레임을 새 장면으로 저장하지 않는다.
- 실패는 경고·기록에 남기고 기존 장면과 탐지 결과를 보존한다. 취소·연결 끊김에도 이미 저장한 장면은 유지한다.
- 검증: 자동/수동 구분·무탐지 수동 장면·디스크 오류·중단 후 보존·모든 프레임 처리·최신 1장 미리보기 유지.
